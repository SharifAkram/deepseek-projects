# deepseek-projects

A collection of Python scripts that use the **DeepSeek-R1:14B** large language model running locally on a **MacBook Air M5** via **Ollama**.

## Technologies

- Python
- Ollama
- DeepSeek-R1:14B
- macOS

## Purpose

This repository is for learning and experimenting with local AI development, including:
- Prompt engineering
- LLM automation
- Python integrations
- Local AI workflows without cloud APIs

## Requirements

- Ollama
- DeepSeek-R1:14B model
- Python 3.11+
- `requests` library

## Run

Start the model:

```bash
ollama run deepseek-r1:14b
```

Run a script:

```bash
python3 embedding_script.py
```
